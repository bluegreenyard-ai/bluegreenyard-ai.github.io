Smart Rainwater Management

The storage system combines rainfall forecasts, current tank levels and hydraulic control to create storage capacity before expected rain events.

Weather Forecast → Expected Inflow → Storage Check → Automatic Action

Rainfall Inflow Calculation

Each roof area generates a different inflow. Therefore, every tank uses its own rainfall-to-volume factor.

3.817 L/mm Tank 1
0.880 L/mm Tank 2
3.431 L/mm Tank 3
0.325 L/mm Tank 4
Expected inflow
Rain forecast [mm] × tank-specific factor [L/mm] = expected inflow [L]

Self-Learning Inflow Model

1. Measure Rain

Actual rainfall is recorded by the weather station.

2. Measure Tank Response

The real increase in tank volume is determined.

3. Calculate L/mm

A new observed inflow factor is calculated.

4. Adapt

Recent valid events gradually update the inflow model.

Forecast → Rain Event → Measurement → Learning → Improved Forecast Calculation
Adaptive system: The inflow factors are not permanently fixed. Valid rain events are evaluated and the model is gradually adapted to the real behaviour of the site.
