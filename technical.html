Smart Rainwater Management

The storage system combines rainfall forecasts, current tank levels and hydraulic control to create storage capacity before expected rain events.

Weather Forecast → Expected Inflow → Storage Check → Automatic Action

System Inputs

🌦️ Rain Forecast

• Open-Meteo
• 1-hour forecast window
• Expected precipitation

• Current water volume
• Available storage capacity
• Minimum / maximum levels

⚙️ System Status

• Pumps
• Valves
• Hydraulic connections

Rainfall Inflow Calculation

Different roof areas are connected to the four storage tanks. Each tank therefore uses an individual rainfall-to-volume factor.

3.817 L/mm Tank 1
0.880 L/mm Tank 2
3.431 L/mm Tank 3
0.325 L/mm Tank 4
Expected inflow

Rain forecast [mm] × tank-specific factor [L/mm]
=
expected inflow [L]

Self-Learning Inflow Model

1. Measure Rain

Actual rainfall is recorded by the weather station.

2. Tank Response

The actual change in tank volume is measured.

3. Calculate L/mm

A new observed rainfall-to-inflow factor is determined.

4. Adapt

Valid events gradually improve the inflow model.

Forecast → Rain Event → Measurement → Learning → Improved Calculation
Adaptive system:
The factors are not permanently fixed. Measured rain events and actual tank responses are used to gradually adapt the model.
